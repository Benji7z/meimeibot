# meimeibot

meimeibot is a discord bot programmed in discord.py featuring many server specific features.

Install the dependencies
```bash
python -m pip install -r requirements.txt
```
Keep in mind that there indeed are very server specific features that you will certainly not be using.


I recommend you make environment variables for the needed API keys such as:

`DISCORD_BOT_TOKEN` - Self explanatory dude  
`GEMINI_API_KEY` - For the AI functionality (can be found in `cogs/ai.py`)  

Launch bot with
```bash
python main.py
```
